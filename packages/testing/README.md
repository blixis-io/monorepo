# @blixis-io/testing

Test helpers for Blixis modules: `createTestBlixis`, fake actors, captured events, and a test database.

```bash
pnpm add @blixis-io/testing @blixis-io/contracts @blixis-io/database @blixis-io/events @blixis-io/kernel
```
