# @blixis-io/database

Postgres access for Blixis modules on Workers and Hyperdrive: the per-request Drizzle `DATABASE` service, tenant scoping, transactions, error translation, and module migrations.

```bash
pnpm add @blixis-io/database @blixis-io/contracts @blixis-io/kernel drizzle-orm hono
```
