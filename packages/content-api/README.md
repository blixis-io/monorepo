# @blixis-io/content-api

The public API of the Blixis content module: `CONTENT_SERVICE`, `CONTENT_TYPE_SERVICE`, entry and content type types, and the `entry.*` and `content-type.*` events. Depend on it instead of the content implementation.

```bash
pnpm add @blixis-io/content-api @blixis-io/contracts
```
