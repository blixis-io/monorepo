# @blixis-io/kernel

The Blixis module kernel: `defineModule` and `createBlixis`, which validates the module graph and serves REST, GraphQL, events, and cron from one Worker.

```bash
pnpm add @blixis-io/kernel @blixis-io/contracts hono
```
