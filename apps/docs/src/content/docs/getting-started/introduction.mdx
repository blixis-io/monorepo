Blixis is a modular headless CMS that runs on Cloudflare Workers. Everything it does — content, assets, users, webhooks — is implemented as **modules**. A module built by you and installed from npm uses exactly the same contracts as the modules shipped with Blixis.

This manual is for **module authors**. It is being written alongside the implementation; the full guide arrives in the next update.
